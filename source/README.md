## Product direction

EcoFarm AI is a safety-first agricultural AI decision-support product combining AI Vision, field context, weather provenance, EcoMind contextual scoring, and confidence-aware safety controls.

Core message: **We don't hide uncertainty; we make it actionable.**

## Recommended architecture

- Marketing website: Framer
- Product application: Next.js + React + TypeScript
- UI: Tailwind CSS + shadcn/ui
- Backend/data: Supabase PostgreSQL + Auth + Storage + Edge Functions
- AI Vision: Gemini initially
- Weather: OpenWeather initially
- Application hosting: Vercel
- Source control: GitHub
